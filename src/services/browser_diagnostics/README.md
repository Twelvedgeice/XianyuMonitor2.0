# 浏览器启动诊断子项目

> 2026-11-08 已拆为独立项目：本机的「浏览器启动诊断」目录。本目录现在只保留兼容入口，实际源码和维护说明以独立项目 README.md 为准。连接位置由 `data/browser-diagnostics-project.json` 配置；报告仍保留在本监测工程。

负责 private1（Chrome）、private_2（Edge）、private_3（Firefox）的启动与连接问题初步排查。它是监测工程内自动运行的诊断模块，不需要另开服务。

## 自动交接

1. 托管监测中，同一个账号在同一轮连续失败两次，`retry_collection` 自动交给此模块。
2. 对两次错误分别分类，只检查出错节点的本地配置、浏览器运行时文件、登录态结构及本地控制端点。
3. 生成 Markdown 排查报告和 JSON 结构记录；任务日志显示 `[浏览器诊断]` 和报告路径。
4. 继续原有账号轮换和 Bark 通知。当前总尝试上限 2 次、冷却 6 小时，检查频率保持已有配置。

诊断固定在第二次失败触发，每轮最多一次。如果页面以后把总尝试次数改成 3 次以上，诊断仍在第二次失败执行，换号则遵守页面上限；若改成 1 次，本轮不会达到诊断阈值。第一次失败后第二次成功，以及取消任务，都不生成双失败报告。手动价格调查仍只浏览一次，不加入重试或自动诊断。

此入口覆盖实际采集尝试里的浏览器启动、连接、搜索和筛选异常。任务尚未进入采集重试入口就失败（例如调度器不能启动 Python、Firefox 后台服务自身无法建立连接），不会伪造“两次采集失败”；可使用下面的手动检查，并检查管理服务日志。

## 报告位置

`data/browser-diagnostics/<账号>/<时间>-<唯一编号>.md`，同名 `.json` 可供后续程序读取。每次事件单独存档，不覆盖其他账号的记录；旧报告可手动归档或删除。

报告包含：时间、账号、触发方式、错误类别、预定义证据标记、当地节点快照和下一步建议。状态 `diagnosed_needs_review` 表示自动初步排查完成，尚未确认根因或修复；不能当作“已经修好”。

| 类别 | 含义与处理 |
| --- | --- |
| browser_startup | 浏览器启动或运行时失败；检查文件和专用目录，必要时只重启故障节点 |
| browser_connection | 本地端点无法连接或浏览器关闭；核对专用后台 |
| platform_verification | 闲鱼验证拦截；遵守冷却，需要时人工验证 |
| login | 登录失效；重新登录并保存后核对身份 |
| filter | 筛选/排序异常；检查页面和搜索响应 |
| timeout | 页面/响应超时；不能仅据此断定账号受限 |
| unknown | 证据不足；结合对应时间的任务日志继续排查 |

分类是基于错误标记的初步判断，快照反映错误发生之后的状态；二者都不是完整根因证明。原始异常仍可在本机任务日志查看，诊断报告不复制原始错误、Cookie 值、后台令牌和带认证参数的 URL。

## 手动检查

在项目根目录的 PowerShell 执行（不打开浏览器、不搜索闲鱼）：

```powershell
$env:PYTHONUTF8 = '1'
.\.runtime-venv\Scripts\python.exe -m src.services.browser_diagnostics --account private_3
```

可换成 `private1` 或 `private_2`。命令返回报告路径；手动检查明确标记 `manual`，不会冒充自动失败事件。

## 运行边界

- 只在失败事件或手动调用时运行，不定期检查闲置账号。
- 只读取出错节点；最多查询其 `127.0.0.1` 健康端点，不访问闲鱼搜索。
- 不自动杀进程、重启浏览器、改 Cookie、解除冷却或切换当前账号；账号轮换由原模块负责。
- 不改变检查频率，不增加采集尝试次数。诊断最多等待 5 秒；失败或超时不掩盖原始采集错误，不阻止后续轮换。超时后的只读工作线程可能完成报告写入。
- 它不会自动唤醒聊天里的 Codex 或启动常驻 AI 子代理。代码修复仍需在聊天中根据报告执行，避免未经验证的自动修改影响正常节点。

## 维护与测试

- `__init__.py`：错误分类、单节点只读检查、报告输出。
- `__main__.py`：手动命令。
- `../account_failover.py`：两次失败的交接入口。
- `../../scraper.py`：传入本轮节点与任务信息。
- `../../../tests/unit/test_browser_diagnostics.py`：分类、触发、取消、脱敏、隔离与故障容错测试。

```powershell
.\.runtime-venv\Scripts\python.exe -m pytest tests/unit/test_browser_diagnostics.py tests/unit/test_account_failover.py tests/unit/test_firefox_runtime.py -q
```

修复浏览器启动代码后，先运行相关测试，再只对目标节点验证启动/身份恢复，确认后按用户授权解除该节点冷却。每次修改还须更新根目录 `WORKLOG_README.md`，列出改动脚本和验证结果。
